Два приложения, одна локальная сеть

Проект состоит из агента для Windows и клиента для Android. Они находят друг друга сами и общаются по WebSocket, интернет не нужен.

Агент на ПК

  • Python 3.11+, живёт в трее
  • замечает активное окно, нагрузку CPU, батарею, простой, сеть
  • считает работу и отдых за день
  • команды: mute, lock, sleep, громкость

Клиент на телефоне

  • Kotlin и Jetpack Compose
  • LED-мордочка на чёрном фоне, движок эмоций с 202 правилами
  • касания, поглаживание, удар по крышке
  • Помодоро, задачи, присутствие и сон

Как событие превращается в реакцию

Нажмите кнопку: агент «пришлёт» событие, а Мотя ответит так, как описано в README.

События идут по очереди. Это упрощённая демонстрация, настоящие правила богаче.

Что готово, а что нет

Проект в активной разработке. Всё ниже взято из README и проверено автором только в той мере, как там написано.

Работает

  • Поиск ПК по mDNS, вход по токену, коду или QR
  • Переподключение, фоновый сервис с уведомлением
  • Каталог из 73 эмоций, три сезонные темы, календарь праздников
  • Касания, поглаживание, удар по задней крышке, 4 мяуканья
  • Присутствие по камере (ML Kit на устройстве), сон ПК и пробуждение по Wake-on-LAN
  • Помодоро, Google Tasks, шаги, сон и пульс из Health Connect, экранное время
  • Блокировка выбранных приложений на время фокуса
  • Paw Intervention на ПК с HTML-окном настроек

Заморожено или не доделано

  • Notion выключен флагом, код сохранён
  • Переключателя тем в интерфейсе нет
  • Часть событий ждёт источников: объятие, «соскучился», события суток
  • Нет автозапуска после перезагрузки телефона
  • Токен сопряжения лежит без отдельного шифрования
  • Датчики телефона, звонки и SMS не подключены
  • Полный ручной прогон всех экранов не делался: release-APK запускался на одном Honor без падений

Ограничения

  • Агент работает только на Windows, установщика и службы нет
  • Windows не умеет блокировать программы без драйвера: Мотя сворачивает окно, его можно открыть снова
  • Wake-on-LAN зависит от BIOS, сетевой карты и роутера
  • Play Protect блокирует APK с доступом к специальным возможностям: ставить нужно через adb
  • Постоянная камера и wakelock тратят батарею

Автотесты по README: 162 JVM-теста ядра и 24 теста приложения на Android, 504 теста агента на Python.

Лапка, которая просит вернуться к работе

Paw Intervention замечает повторяющиеся отвлечения: две минуты подряд или три возврата к одному приложению за десять минут. Тогда поверх рабочего стола выглядывает лапка с карточкой. Отказ принимается без обиды, предложение не повторяется 45 минут.

Ниже прототип из файла paw-intervention.html. Нажимайте кнопки прямо в карточке: лапка отреагирует. На ПК тот же код рисует прозрачное окно WebView2, а без него запускается запасной вариант на Tk.

Что агент видит и что нет

Активное окноИмя процесса. Заголовки окон не читаются.
БраузерТолько домен и его категория. Путь, параметры, заголовок вкладки и содержимое страницы не читаются, почта, банки и мессенджеры исключены.
Уведомления WindowsПриложение и номер уведомления. Заголовок, текст и отправитель не запрашиваются.
Камера телефонаЛицо ищет локальная модель, кадры не сохраняются и не уходят в сеть. Камеру можно выключить.
Здоровье и экранное времяНа ПК уходят только дневные итоги: шаги и минуты. Сырые записи остаются на телефоне.
СетьТрафик идёт только внутри локальной сети, подключения из публичных адресов отклоняются.

Запуск

Это инструкция для разработчика, а не установщик. Нужны Python 3.11+, JDK 17 и Android SDK с platform 36.

Агент на Windows

python -m pip install -r requirements.txt
python -m companion_agent --open-firewall
python -m companion_agent

Откройте в трее «Показать QR» и отсканируйте его в приложении. Телефон и ПК должны быть в одной сети Wi-Fi.

Клиент для Android

cd android
./gradlew :core:coreTest :app:assembleDebug
./gradlew :app:assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk

Вход в Google Tasks на телефоне зависит от отпечатка подписи: после смены ключа его нужно добавить в Google Cloud Console.
